## Game Night Manager

`game-night/index.html` is a single-page app for running a poker table and a FIFA tournament at the same time:

- **Players**: add everyone, mark who's at poker and who's in FIFA (or both), or do a random 6/6 split.
- **Poker**: blind clock with auto-rising levels, seat map with dealer button, buy-ins/rebuys, busts, tournament payouts or cash-game chip counts, and a "who pays whom" settle-up.
- **FIFA**: round-robin league (once or home and away), league table, then semis + final or a straight final, with penalties for knockout draws.

Open the file in a browser to use it on one device (saved in that browser).
