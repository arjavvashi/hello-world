## Game Night Manager

`game-night/index.html` is a single-page app for running a poker table and a FIFA tournament at the same time:

- **Login**: everyone taps their name (no password). Every buy-in and result records who entered it.
- **Live FIFA**: anyone starts a match by picking the two players and their teams, enters goals live, and taps Full time. Matches count as group stage, knockout (with penalties) or friendly. Results can be edited or deleted.
- **Poker**: chip set (white 10¢, red 20¢, green 50¢, purple $1, blue $5; $20 stack = 10 white, 10 red, 4 green, 10 purple, 1 blue), a chip counter for cash-outs, one-tap buy-ins (standard or custom amount) with a timestamped log, then cash-outs at the end of the night and a "who pays whom" settle-up.
- **Leaderboard**: a table for each group, knockout results, an overall FIFA table, and a poker table (buy-ins, paid in, net).
- **Players & groups**: add players, create groups, and assign each player a group and usual team.

Open the file in a browser to use it on one device (saved in that browser).
